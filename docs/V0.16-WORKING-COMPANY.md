# Eason One v0.16 — Working Company Release

Status: formal mainline release
Date: 2026-08-10

v0.16 is not a demo branch. It continues the existing Eason One Runtime Spine and replaces the thin Founder cutover with a working-company experience grounded in real persisted state.

## Shipped in this release

- Company re-entry surface built from real Project, Work, Artifact, Decision, Meeting, Attention and CompanyEvent state.
- Project Outcome Space with a current frontier, meaningful changes, real work products, decisions, meetings, cost and Founder authority.
- Persistent Employee professional-life surface with current work, recorded opportunity allocation, eligible-not-selected history when the runtime actually recorded an eligible pool, contribution provenance, learning history and intelligence-binding history.
- Human-facing company truth remains filtered from technical runtime noise; raw execution machinery stays available under Advanced.
- Formal Founder Project creation remains a zero-provider-cost state mutation; CEO planning/execution is a separate governed action.
- Existing Meeting Room is preserved rather than replaced by a dashboard or virtual-office simulation.

## Deliberately not fabricated

The current database does not yet contain an operational Employee personal-wallet / Store / capability-asset ledger. v0.16 therefore does not invent wallet balances, Store purchases, skill scores or economic history. Those systems will be added to the same formal mainline when their runtime state is real.

## Product rule for this release line

Build -> use -> observe -> find failures -> change -> build again.

Research constrains the system, but unverified product hypotheses remain changeable through real use. Every later change should preserve Company Truth and the evidence needed to explain why the system changed.
