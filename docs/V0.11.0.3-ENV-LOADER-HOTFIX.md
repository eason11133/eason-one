# Eason One V0.11.0.3 — Project `.env` Loader Hotfix

The `.env` file was preserved, but the application depended on Flask CLI's optional dotenv integration while `python-dotenv` was not installed. A new PowerShell process therefore started Eason One without provider credentials.

This hotfix loads `D:\school\eason-one\.env` directly at package startup using the Python standard library. Existing process environment variables remain authoritative, secret values are never logged, and real provider calls are not made during installation or verification.
