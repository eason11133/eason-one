# Eason One v0.15.3 — Founder Read Path Performance

- Founder GET routes never run vNext bootstrap/backfill or maintenance reconciliation.
- Project cards batch Task counts and real Operations instead of N+1 per Project.
- Project results batch latest AgentRun lookup per Task.
- History uses a bounded recent-results feed instead of walking every Project.
- Stale completed-operation Founder gates are hidden by the read projection without mutating audit history.
- Production maintenance runs only after verification passes.
- Installer backs up the SQLite database before maintenance and restores it on rollback.
