# Eason One V0.11.0.2 Installer Regression Fix

## Failure corrected

V0.11.0.1 rolled back during its first focused regression test because Flask's
`TESTING` shortcut returned `source="testing"` before the explicitly supplied
installer readiness snapshot was loaded. The test expected `source="persisted"`.

This was an installer verification-path defect, not a Provider call, Codex run,
or database migration failure. Rollback restored the pre-install files and
SQLite database.

## Correction

- An explicit `EASON_ONE_CODEX_READINESS_FILE` is loaded before the TESTING
  shortcut when `force_probe=False`.
- The explicit snapshot branch only reads a local JSON file and cannot launch a
  subprocess.
- The original TESTING fallback remains in place when no explicit snapshot is
  configured.
- Production Founder pages continue to read the installer-persisted snapshot.
- Real Engineering execution continues to use `force_probe=True` immediately
  before Codex runs.
