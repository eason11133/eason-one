# Eason One V0.11.1 Main Flow Recovery

This release is limited to the usable Founder path:

Founder -> CEO proposal -> Founder approval -> Real Mission -> Engineer -> local WSL2 Codex -> persisted evidence -> Founder delivery.

It does not redesign the rest of Headquarters.

## Blocking fixes

- Loads the existing repository `.env` at process startup without printing or overriding secrets.
- Excludes SYSTEM_VALIDATION Missions and their Runs from CEO work scope.
- Does not bind a new Founder request to an unrelated paused Real Mission.
- Routes remove/replace/refactor/upgrade/eliminate requests as governed work.
- Stamps new CEO Operations as REAL_WORK and prevents validation history from satisfying duplicate detection.
- Persists CEO success and failure replies.
- Reconstructs the proposal/Mission action link after refresh from the persisted Run -> Operation relationship.
- Avoids the duplicate transient browser error reply.

## Verification

The installer runs the V0.11 focused runtime tests plus environment, dialogue, exact intent, proposal-refresh, validation-exclusion, and simulated Founder-to-Codex delivery tests. It does not call a Provider or execute a real Codex task.
